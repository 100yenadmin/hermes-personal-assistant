# VA scorecard

Run `python -m evals.scorecard --version V --commit SHA --lab DIR --as-of YYYY-MM-DD --out DIR`, optionally repeating `--lab` and adding `--live FILE`. The JSON preserves input roots; the Markdown omits paths and URLs. Only completed runs pinned to the full PA commit count, and partial checks never establish a full-area pass. Live task dates are ISO dates: due dates supply the last task date (the export has no completion timestamp), the span counts both endpoint days, and pending tasks count as failures only after their due date. Missing owner baseline/day-30 records leave day-30 unproven; first-pass task types count distinctly. The command reports failures with exit 0 and rejects bad input with exit 2. Synthetic tests prove scoring rules, not real lab quality, publication, runtime activation or customer parity. Related issue: #48.
