`web` identifies a public browser ordering route, not live checkout proof. `unverified` marks a fact public pages did not establish; check it before promising completion. An app-only route means preparing a list, then giving the user exact app steps to select the hotel address, items, substitutions and review total, stopping before order submit.
Verify front desk acceptance versus room delivery, reception hours and cold-storage feasibility. Include the hotel name and approved meeting point; share the room number only after the user approves the order and only when required. Keep any cart staged at user login, CAPTCHA or code verification and hand that step to the user.
