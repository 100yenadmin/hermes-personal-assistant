# Japan and Korea taxis and airport alternatives

Prepare the exact pickup zone, luggage, local time and fare terms; compare airport rail/bus options before seeking approval for any request, reservation or ticket purchase.

`web` is a documented browser route, not a completed capability-lab checkout. Requirements labeled `unverified` need live checking. GO accepts supported overseas phone numbers; SMS verification still belongs to the user, as described on its [English guide](https://go.goinc.jp/en).
For app-only service, stage pickup/dropoff in local script, terminal/meeting point, time, passengers, bags and fare class. Give exact app steps to the quote/review screen; pause for user login/SMS and obtain explicit yes before any request or reservation. Never promise advance dispatch equals a guaranteed vehicle.
Evidence: [Uber Japan advance reservations](https://www.uber.com/jp/en/ride/how-it-works/reserve/); [Limousine Bus web guide](https://www.limousinebus.co.jp/file/bus_settlement-reservation_en.pdf); [k.ride airport service notice](https://www.kakaomobility.com/notices/detail/개인위치정보처리방침-개정-안내--382). Other row URLs document the selected services.
